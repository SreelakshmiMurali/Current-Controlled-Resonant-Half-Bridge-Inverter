# Current Controlled Resonant Half-Bridge Inverter

This project focuses on designing a **half-bridge resonant inverter** using **frequency-based current control** to achieve **soft-switching (ZVS/ZCS)** and improve efficiency in high-frequency power conversion systems.

---

## ⚙️ Objective
To study, design, and implement a resonant inverter that minimizes switching losses and operates efficiently under various load conditions.

---

## 🧩 Tools & Components
- **Simulation Tools:** MATLAB/Simulink, LTSpice  
- **Hardware Components:** MOSFETs, Gate Driver (TLP250), LC Resonant Tank  
- **Control System:** Frequency-based current control using microcontroller/DSP

---

## 🔍 Key Features
- Soft-switching achieved through resonant tank design  
- Analysis of **ZVS/ZCS operation regions**  
- Frequency-controlled modulation for efficient power conversion  
- MATLAB & LTSpice models for simulation and verification

---

## 🧪 Results (Simulation & Hardware)
| Parameter | Result |
|------------|---------|
| Resonant Frequency | ~40 kHz |
| Soft-Switching | Achieved (ZVS/ZCS) |
| Efficiency Improvement | >15% compared to hard-switched inverter |

---

## 🧰 Applications
- Wireless Power Transfer (WPT) systems  
- Electric Vehicle (EV) onboard chargers  
- High-frequency power supplies
